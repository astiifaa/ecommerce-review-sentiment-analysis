# Sentiment Analysis of E-Commerce Reviews

This repository contains an ongoing academic project focused on sentiment analysis of e-commerce product reviews using text mining techniques and TF-IDF feature extraction.

## Project Overview

The project aims to analyze customer review sentiments by processing textual review data and applying basic machine learning and natural language processing concepts.

## Tools & Technologies

* Python
* Google Colab / Jupyter Notebook
* TF-IDF
* Text Mining
* CSV/XLSX Dataset Processing

## Current Progress

* Data preprocessing
* Text cleaning
* TF-IDF feature extraction
* Initial sentiment analysis
